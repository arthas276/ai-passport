# TUNER 口袋半音调音器 - 产品需求文档

> 状态：可进入固件实现
> 硬件：FoloToy AI Passport（ESP32-C3，240x320 ST7789P3，三 ADC 按键，ES8311）
> 目标分支：feature/tuner（自上游 main 建立）
> PRD 版本：v1.3（2026-11-19：中文界面（文楷 20px 子集，生成时自审字形）；长按 DOWN 进设置屏：A4 基准 415-466 Hz、移调显示（关/降B/降E/F）、音量；四项设置（模式/音量/A4/移调）NVS 持久化；弦进度点阵、指针 EMA 平滑、全弦调准状态；v1.2（2026-10-21：弦模式长按 UP 播放当前目标弦参考音 ~1.2 秒，播放期间暂停拾音）；v1.1（2026-10-11：吉他/尤克里里/小提琴弦模式（锁定自动进下一弦）、哼唱模式（音域跟踪）、OK 长按切模式）；v1.0 为纯半音核心）
> 日期：2026-11-19
> 模式：用户授权自主开发；音高检测器移植自 feature/ear-buddy 的
> ear_pitch.c（同仓库，2026-09-29 真机验证过）。

## 1. 产品概述

- UI 名称：TUNER，可穿戴半音调音器
- 完全离线；无网络、无账号；v1.3 起四项设置（模式、音量、A4 基准、
  移调）持久化在 NVS
- 检测 82.4 Hz（吉他低音 E2）到约 1000 Hz 的持续音，显示最近的
  音名+八度、频率、±50 音分指针
- ±5 音分绿区锁定提示音

## 2. 硬件事实（bsp_pins.h / specs / AGENTS）

- 板级基线同仓库指南；电量按默认约定显示在右上角
  （bsp_battery_soc()，-1 显示 --%）；ES8311 以 16kHz 单声道采集+播放
- 上游已启用 Montserrat 14/20；v1 在 sdkconfig.defaults 增加
  Montserrat 48 用于大字号音名。v1.3 起中文界面文案（标题、辅助行、
  状态词、提示行、设置行）用生成的 20px 文楷子集渲染
  （tools/tuner/gen_assets.mjs，生成时自审字形）；音名、频率读数与
  电量保持 Montserrat ASCII
- 无 RTC；v1 无持久化特性

## 3. 行为、画面与按键

单屏（全新设计，不沿用 demo 外壳），长按 OK 循环切换五个模式：
CHROMATIC 纯半音（默认）、GUITAR（E2 A2 D3 G3 B3 E4）、UKULELE
（G4 C4 E4 A4，reentrant）、VIOLIN（G3 D4 A4 E5）、VOICE 哼唱。

- 顶部：模式名标题（v1.3 起为中文：自由/吉他/尤克里里/小提琴/
  人声）；右上角电量
- 中央：Montserrat 48 大字音名——弦模式显示当前目标弦，其余显示最近
  音；无声时 "--"。v1.3 起自由模式（纯半音/哼唱）开启移调后显示
  记谱音高（实际音 + 移调量）；弦目标始终显示实际音，哼唱音域行
  随移调同步。辅助行：弦模式显示「弦 n/m」，VOICE 显示
  「音域 C3-A4」（本次会话所有有声帧的最低/最高音）。
  下方 Montserrat 20 显示频率
- 指针条宽 200px，围绕参考音（目标弦或最近音）±50 音分，±5 音分绿区，
  游标两端限位，v1.3 起 EMA 平滑（系数 0.35，无声/换弦时重置；锁定
  判定仍用原始音分）；状态词为中文（偏低/偏高/准了）
- 锁定：连续 8 帧入绿区 -> 「准了」（绿）+ 一声提示音；弦模式随即
  自动进下一根弦（循环）。v1.3：每根弦锁定后点亮进度点
  （已调绿/当前青/待调灰蓝），全部调准显示「全弦调准」
- OK 单击冻结/恢复读数（提示行显示「已暂停 OK 继续」）；OK 长按切
  模式（重置弦序/音域/进度）；UP/DOWN 在弦模式中换目标弦（UP 长按
  播当前目标弦参考音 ~1.2 秒，播放时暂停拾音）；DOWN 长按进设置屏；
  任意按键点亮背光；空闲 10 秒背光 30%（仓库功耗约定）。底部提示行
  每 2.5 秒轮换，保证所有手势都在 240px 内留屏提示
- 设置屏（v1.3）：三行——A4 基准（415-466 Hz，OK 步进 +1 循环）、
  移调（关/降B/降E/F）、音量（0-100，OK 步进 +10 循环）；UP/DOWN 选
  行，OK 调整，OK 长按保存（含当前模式）并返回。A4 即时重校准音名、
  参考音与绿区；默认 440/80/关/自由与 v1.2 行为完全一致

## 4. 技术架构

main/
  tuner.h           - 共享常量/类型（[PURE] 头文件）
  tuner_pitch.c/.h  - [PURE] 自相关检测器，移植自 feature/ear-buddy 的
                      ear_pitch.c：RMS 门限、最早显著峰 + 整数
                      分频复核，防八度误判、抛物线插值、median-3；全音域音名
  tuner_modes.c/.h - [PURE] 模式表（弦调音）、弦步进与锁定推进、
                      哼唱音域跟踪
  tuner_audio.c/.h  - worker：16kHz 连续采集 -> 检测 -> 事件队列；
                      提示音在帧间串行播放
  tuner_ui.c/.h     - 单屏 LVGL UI + 背光空闲管理
  main.c            - BSP 初始化 -> 设置加载/应用 -> 输入/音频分发
  tuner_settings.c/.h - [PURE] 设置模型：默认值、清洗、移调表
  tuner_store.c/.h  - NVS 持久化（4 个标量键；缺失即默认）
  tuner_font_20.c   - 生成的文楷 20px 子集（tuner_strings.h 字面量）
tests/test_tuner_pitch.c - 全音域正弦、低音 E2 检测、八度安全、
                      median-3、音名、门限；v1.3：A4 校准数学
tests/test_tuner_modes.c  - 模式表、循环顺序、弦步进、音域跟踪；
                      v1.3：弦进度位图、移调、EMA
tests/test_tuner_settings.c - 默认值、清洗、移调循环
tools/tuner/gen_assets.mjs - 字体子集生成器 + 字形自审

[PURE] 模块零 IDF/LVGL 依赖，cc -std=c11 -Wall -Wextra -Werror 编译
通过并注册进 tools/validate.sh。

## 5. 风险与 AI 默认决策

| 决策 | 值 | 理由 |
| --- | --- | --- |
| 量程 70-1000 Hz | 覆盖 E2..B5 | 吉他/贝斯低音 E 到小提琴 E5 |
| 绿区 ±5 音分 | 紧但可见 | 调音器通行显示 |
| 锁定 = 8 帧（约 0.5 秒） | 稳不拖沓 | 每帧 64ms |
| 不做琴弦目标标记 | v1.1 已加乐器模式 | 吉他/尤克里里/小提琴弦 + 自动进弦 |
| 不做贝斯模式 | v1.1 范围外 | 低音 E1 41Hz 低于 70Hz 检测下限，需更长帧 |
| 设置持久化（v1.3） | 4 个标量键 | 模式/音量/A4/移调；缺失键取默认（自由/80/440/关）；无 blob、无需迁移 |
| 风险：低音弦噪声下检测 | 合成测试 + 真机验证 | 最低周期约 229 样本 vs 1024 帧长 |
