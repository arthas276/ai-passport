## 1. 产品概述

- UI 名称：BREATHE - 口袋呼吸引导伴侣
- 完全离线；无网络、无账号、不用麦克风
- 七种引导节奏（六预设 + YOURS 自定义）+ 音量可调；
  终身累计分钟数/周期数/次数
- 天生闭眼可用：吸气时柔和提示音上行滑音、呼气时下行滑音、
  屏息时淡出为静音 - 闭着眼也能跟着练

## 2. 硬件事实

- 与仓库指南相同的板级基线；右上角电量百分比
  （bsp_battery_soc()，-1 -> "--%"）；ES8311 以 16 kHz 单声道播放
- Montserrat 14/20/48（48 加入 sdkconfig.defaults，用于大号倒计时/数值，
  同 feature/tuner；UI 文案为 ASCII 英文 - 内置字体无中文字形）
- 无 RTC -> 无日期、无打卡连击；持久化只有终身计数
- 连续播放喂入延迟规则（硬件指南 8.1）：NVS 写入与音量变更只在
  播放之外进行；DMA 余量 90 ms，整数合成器保持 >10 倍实时余量

## 3. 引导模式（v1.3）

| 模式 | 吸气 | 屏息 | 补吸 | 呼气 | 屏息2 | 周期 | 体感 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| FLOW | 5.5 秒 | - | - | 5.5 秒 | - | 11 秒 | 相干呼吸，约 5.5 次/分 |
| CALM | 4 秒 | 7 秒 | - | 8 秒 | - | 19 秒 | 4-7-8 放松 |
| SIGH | 2.5 秒 | - | 1.5 秒 | 7 秒 | - | 11 秒 | 生理性叹息：两次吸+长呼，快速降速（v1.3） |
| BOX | 4 秒 | 4 秒 | - | 4 秒 | 4 秒 | 16 秒 | 箱式呼吸，专注 |
| SLEEP | 4 秒 | - | - | 6 秒 | - | 10 秒 | 延长呼气，睡前降速（v1.2） |
| WAKE | 6 秒 | - | - | 3 秒 | - | 9 秒 | 吸长呼短，晨间唤醒（v1.2） |
| YOURS | 1-10 秒 | 0-10 秒 | - | 1-10 秒 | 0-10 秒 | 自定 | 用户自定义节奏，NVS 持久化（v1.3，默认 5+5） |

零时长相位直接跳过，不作为相位出现。相位顺序：吸气→屏息→补吸
（INHALE2，仅 SIGH 预设使用）→呼气→屏息2。

## 4. 行为、界面与按键

- HOME：标题 "BREATHE"，右上电量；列表 FLOW / CALM / SIGH / BOX /
  SLEEP / WAKE / YOURS / SETUP（v1.3 八行 33px 间距），各带副行
  （相位时长 / YOURS 实时摘要）；底部终身统计 "N min - N cycles"。
  UP/DOWN 移动选中（循环），OK 进入（YOURS 同预设直接开始）。
  闲置 10 秒背光降到 30%（仓库省电惯例）；任意按键唤醒。
- SETUP（v1.3）：DURATION（FREE/1/3/5 MIN，OK 循环）、GLOW
  （BRIGHT/NIGHT/DARK，OK 循环）、VOLUME（OK 进大屏调节）、
  YOURS（副行实时显示自定义摘要，OK 进 EDIT）四行；
  OK 长按返回 HOME；VOLUME/EDIT 屏返回 SETUP。
- EDIT（v1.3）：YOURS 节奏编辑屏，四行 IN/HOLD/OUT/HOLD2；
  UP/DOWN 调整选中行的秒数（吸/呼 1-10，屏息 0-10，环绕无死键，
  行内副行实时显示 "N s"）；OK 逐行下移，末行（HOLD2）上 OK 保存
  并返回 SETUP；OK 长按取消返回（丢弃未保存修改）。胶囊提示随选中
  行切换："UP/DOWN: SEC  OK: NEXT" / "OK: SAVE  LONG: CANCEL"。
- SESSION：先 3 秒 "GET READY" 倒计时（每秒一声轻提示音），随后
  循环引导：中央圆随吸气变大、呼气变小（SIGH 补吸时自 3/4 处继续
  胀满，相位文字 "TOP UP"）；相位文字 + 该相位剩余秒数；
  周期计数与已练时间 M:SS（定时会话改为剩余时间倒计时）。背光以
  100% 开始；GLOW 为 NIGHT/DARK 时 10 秒无操作后降到 12% / 0%，
  任意按键回亮窥屏。OK 长按结束（柔和上行尾音）并进入 SUMMARY。
  定时会话在引导时长达标后的第一个吸气起点自动收尾——绝不把呼吸
  切成半截。
- SUMMARY：本次（周期数、时间、满 1 分钟时附呼吸节奏 PACE）+
  终身累计，跨越里程碑时显示 "MILESTONE! N MIN"；统计在此处、播放
  停止后一次性落盘；OK 返回 HOME。
- 声音引导：吸气 = 柔和滑音约 G3->D4（196->294 Hz），呼气反向，
  屏息淡出为静音；结束尾音 E5->A5；音量跟随设置。
  滑音区间 A3->E4（220->330 Hz）；SIGH 补吸再上滑 E4->G4
  （330->392 Hz），含补吸的模式呼气自 G4 长落至 A3。

## 5. 技术架构

```text
main/
  breath.h           - 共享常量/类型（[PURE] 头文件）
  breath_engine.c/.h - [PURE] 模式表 + 会话时间线：流逝毫秒
                      -> 相位 / 进度 / 剩余；零时长屏息跳过；
                      周期与分钟累计；v1.3 运行时表（init /
                      pattern 访问器 / set_custom 校验写入
                      YOURS 槽位，会话启动时快照防编辑竞态）
  breath_tone.c/.h   - [PURE] 整数波表滑音渲染器（波表方法移植自
                      feature/ear-buddy ear_tone.c）：逐样本相位步进
                      插值实现线性频率滑音，attack/release 包络，
                      屏息用淡出武装
  breath_audio.c/.h  - 拥有会话时钟的音频工作线程（采样计数 ->
                      流逝毫秒）：按 512 采样块渲染，在采样精确的
                      相位边界重新武装滑音，以 10 Hz 向 UI 发事件，
                      播放结束尾音；所有 bsp_audio 调用在此串行化
  breath_store.c/.h  - NVS 命名空间 "breathe"：vol/du/gl +
                      ci/ch/co/c2（YOURS 秒数，v1.3，部分损坏
                      回退默认 5+5）/ssn/min/cyc/ms；
                      失败一律降级为默认值 + 记日志
  breath_ui.c/.h     - LVGL：HOME / SETUP / VOLUME / EDIT / SESSION /
                      SUMMARY 六屏 + 闲置调光 + 电量刷新
  main.c             - BSP 初始化 -> 事件队列 -> 输入/音频分发
                      （key_guard 接线强制；同 feature/tuner 模式）
tests/test_breath_engine.c, tests/test_breath_tone.c
```

[PURE] 模块：零 IDF/LVGL 依赖；cc -std=c11 -Wall -Wextra -Werror
编译；在 tools/validate.sh 注册。

时钟归属：音频工作线程的采样计数是唯一会话时钟；UI 只渲染它以
10 Hz 发来的事件（不存在第二个会漂移的时钟）。

## 6. 风险与 AI 默认决策

| 决策 | 取值 | 理由 |
| --- | --- | --- |
| 滑音区间 220-330 Hz | 上/下行纯四度（A3->E4） | 方向感明确、平和、小喇叭友好 |
| 默认音量 70 | 折中 | 比 80 轻、小喇叭上听得清；用户可步进调节 |
| v1 无暂停 | OK 长按直接结束 | 暂停会复杂化时间线；引导呼吸很少需要暂停 |
| 无时长预设 | 想练多久练多久 | 对健康类更友好；界面更少 |
| 无连击打卡 | 无 RTC | 只保留诚实的终身计数 |
| YOURS 秒数界 1-10/0-10 | 编辑环绕 + 引擎校验双保险 | 界内必为合法周期（吸/呼非零）；NVS 越界整体回退默认 |
| 会话启动快照模式结构 | 运行时槽位可能被 SETTINGS 编辑 | 快照后互不可见，免锁 |
| NVS 只在播放外写 | 指南 8.1 | 规避 Flash 停顿爆音 |
| 风险：音量 70 下小喇叭的滑音可闻度 | 真机验证 v1.1 | 方向清晰度 2026-10-16 真机已确认 |
