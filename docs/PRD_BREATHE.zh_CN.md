# BREATHE - 口袋呼吸教练

> 状态：待固件实现
> 硬件：FoloToy AI Passport（ESP32-C3、240x320 ST7789P3、三 ADC 按键、ES8311）
> 目标分支：feature/breathe（基于上游 main，含 PR #107）
> PRD 版本：v1.1（2026-10-16：停止淡出消除长按 OK 爆音、尾音零交叉起振+
> 边沿包络、默认音量 60→70；v1.0 初版）
> 模式：创作者选定的新独立玩法（呼吸陪伴）；音色渲染器血统：
> ear_tone.c 整数波表（2026-09-29 真机验证）。

## 1. 产品概述

- UI 名称：BREATHE - 口袋呼吸引导伴侣
- 完全离线；无网络、无账号、不用麦克风
- 三种引导模式 + 音量可调；终身累计分钟数/周期数/次数
- 天生闭眼可用：吸气时柔和提示音上行滑音、呼气时下行滑音、
  屏息时淡出为静音 - 闭着眼也能跟着练

## 2. 硬件事实

- 与仓库指南相同的板级基线；右上角电量百分比
  （bsp_battery_soc()，-1 -> "--%"）；ES8311 以 16 kHz 单声道播放
- Montserrat 14/20/48（48 加入 sdkconfig.defaults，用于大号倒计时/数值，
  同 feature/tuner；UI 文案为 ASCII 英文 - 内置字体无中文字形）
- 无 RTC -> 无日期、无打卡连击；持久化只有终身计数
- 连续播放喂入延迟规则（硬件指南 8.1）：NVS 写入与音量变更只在
  播放之外进行；DMA 余量 90 ms，整数合成器保持 >10 倍实时余量

## 3. 引导模式（v1）

| 模式 | 吸气 | 屏息 | 呼气 | 屏息2 | 周期 | 体感 |
| --- | --- | --- | --- | --- | --- | --- |
| FLOW | 5.5 秒 | - | 5.5 秒 | - | 11 秒 | 相干呼吸，约 5.5 次/分 |
| CALM | 4 秒 | 7 秒 | 8 秒 | - | 19 秒 | 4-7-8 放松 |
| BOX | 4 秒 | 4 秒 | 4 秒 | 4 秒 | 16 秒 | 箱式呼吸，专注 |

零时长相位直接跳过，不作为相位出现。

## 4. 行为、界面与按键

- HOME：标题 "BREATHE"，右上电量；列表 FLOW / CALM / BOX / VOLUME，
  各带副行（相位时长 / 当前音量百分比）；底部终身统计
  "N min - N cycles"。UP/DOWN 移动选中（循环），OK 进入。闲置 10 秒
  背光降到 30%（仓库省电惯例）；任意按键唤醒。
- VOLUME：大号数值 + 进度条；UP/DOWN 每次 ±10（0..100，默认 70），
  OK 返回 HOME（落盘）。
- SESSION：先 3 秒 "GET READY" 倒计时（每秒一声轻提示音），随后
  循环引导：中央圆随吸气变大、呼气变小；相位文字 + 该相位剩余秒数；
  周期计数与已练时间 M:SS。会话中背光常亮；OK 长按结束（柔和上行
  尾音）并进入 SUMMARY。
- SUMMARY：本次（周期数、分钟数）+ 终身累计；统计在此处、播放
  停止后一次性落盘；OK 返回 HOME。
- 声音引导：吸气 = 柔和滑音约 G3->D4（196->294 Hz），呼气反向，
  屏息淡出为静音；结束尾音 E5->A5；音量跟随设置。
  滑音区间 A3->E4（220->330 Hz）。

## 5. 技术架构

```text
main/
  breath.h           - 共享常量/类型（[PURE] 头文件）
  breath_engine.c/.h - [PURE] 模式表 + 会话时间线：流逝毫秒
                      -> 相位 / 进度 / 剩余；零时长屏息跳过；
                      周期与分钟累计
  breath_tone.c/.h   - [PURE] 整数波表滑音渲染器（波表方法移植自
                      feature/ear-buddy ear_tone.c）：逐样本相位步进
                      插值实现线性频率滑音，attack/release 包络，
                      屏息用淡出武装
  breath_audio.c/.h  - 拥有会话时钟的音频工作线程（采样计数 ->
                      流逝毫秒）：按 512 采样块渲染，在采样精确的
                      相位边界重新武装滑音，以 10 Hz 向 UI 发事件，
                      播放结束尾音；所有 bsp_audio 调用在此串行化
  breath_store.c/.h  - NVS 命名空间 "breathe"：vol/ssn/min/cyc；
                      失败一律降级为默认值 + 记日志
  breath_ui.c/.h     - LVGL：HOME / VOLUME / SESSION / SUMMARY 四屏 +
                      闲置调光 + 电量刷新
  main.c             - BSP 初始化 -> 事件队列 -> 输入/音频分发
                      （key_guard 接线强制；同 feature/tuner 模式）
tests/test_breath_engine.c, tests/test_breath_tone.c
```

[PURE] 模块：零 IDF/LVGL 依赖；cc -std=c11 -Wall -Wextra -Werror
编译；在 tools/validate.sh 注册。

时钟归属：音频工作线程的采样计数是唯一会话时钟；UI 只渲染它以
10 Hz 发来的事件（不存在第二个会漂移的时钟）。

## 6. 风险与 AI 默认决策

| 决策 | 取值 | 理由 |
| --- | --- | --- |
| 滑音区间 220-330 Hz | 上/下行纯四度（A3->E4） | 方向感明确、平和、小喇叭友好 |
| 默认音量 70 | 折中 | 比 80 轻、小喇叭上听得清；用户可步进调节 |
| v1 无暂停 | OK 长按直接结束 | 暂停会复杂化时间线；引导呼吸很少需要暂停 |
| 无时长预设 | 想练多久练多久 | 对健康类更友好；界面更少 |
| 无连击打卡 | 无 RTC | 只保留诚实的终身计数 |
| NVS 只在播放外写 | 指南 8.1 | 规避 Flash 停顿爆音 |
| 风险：音量 70 下小喇叭的滑音可闻度 | 真机验证 v1.1 | 方向清晰度 2026-10-16 真机已确认 |
