# 口袋密码卡 - 离线派生密码卡

> 状态：新应用，2026-11-09 首次实现；待真机验证
> 硬件：FoloToy AI Passport（ESP32-C3，240×320 ST7789P3，三键 ADC，ES8311）
> 目标分支：feature/pwcard（基于上游 main）
> PRD 版本：v1.2（2026-11-16：密码屏长按上键删站/长按下键改站（过双确认，屏上有提示行）；向导加模式步——普通密码 4-16 位（卡上连续格）或 PIN 4-6 位（域分离独立流，永不印在可打印卡上）；种子页加 CRC-8 校验行，设置新增「恢复种子」打字轮录入（换机不再依赖宿主工具）；存储 v2（440 字节，站点加模式字节），读取时自动迁移 v1.0 的 408 字节 blob；v1.0（2026-11-09）：初版——首次开机用 esp_fill_random 生成 128-bit 种子，经 xoshiro128\*\* 派生出固定的 8×10 字符网格；每个站点只是「行+列+长度」，密码就是同一条 80 格流上从该位置起的若干字符（越过末尾回绕）；密码默认遮蔽，OK 显示 8 秒倒计时后自动遮回，任何非 OK 键立即遮蔽；站名用三键转轮输入；种子可按十六进制查看，换设备抄写即可复现同一张卡；55 字符去混淆字母表 ≈5.78 bit/字符，8 位密码 ≈46.2 bit 卡内熵；闲置 12 秒背光调暗、60 秒深睡、按键唤醒）
> 模式：派生、回绕、种子十六进制、记录校验与闲置电源逻辑均为纯 C 可主机测试；C 侧生成流与 tools/pwcard/gen_assets.mjs 的独立实现在 tests/test_pw_core.c 交叉对拍

## 用法

开机进入卡视图：列头 A-J、行号 1-8 的 8×10 网格，游标行高亮。不进入硬件测试菜单。

- 卡视图：UP/DOWN 移动游标行（长按连发）。OK 进站点列表，长按 OK 进设置。
- 站点列表：UP/DOWN 选行，OK 看密码，长按 OK 回卡视图。列表末尾永远有一条固定的「添加站点」行（满 32 条后消失）。行内只显示站名——行列/列/长度摘要只在真正用到它的密码屏展示。页脚始终明示当前手势。
- 密码屏：默认遮蔽。OK 显示 8 秒并配缩短的倒计时条，到时自动遮回；再按 OK（或任意 UP/DOWN）立即遮蔽。长按 OK 返回。长按上键删除该站点（过双确认屏）；长按下键重开预填好的向导就地编辑。两个手势都写在页脚上方的两行淡色提示里。PIN 站点在名称行尾缀「 PIN」；摘要行仍是行/列/长度。
- 添加/编辑向导：五步——模式（普通密码或 PIN）、行 1-8、列 A-J、长度（普通 4-16、PIN 4-6）、名称打字轮：UP/DOWN 滚动 7 格窗口（A-Z 0-9 连字符 点 空格，尾部有可见的「删」「完」条目）；OK 打入高亮条目（或删除/完成），长按 OK 取消。已打内容带下划标光标显示在轮上方。编辑模式下标题变为「编辑站点」，完成时原地覆盖该条。
- 设置：重生成卡（两次确认：旧密码全部失效）、查看种子（32 个十六进制字符 + CRC-8 校验行）、恢复种子（0-9 a-f 打字轮录入 32 位；未满显示 n/32，满 32 位显示待确认种子的 CRC；全零种子拒绝；确认后换种子并警告全部密码改变——已录站点保留）、清空站点（两次确认）、玩法说明。首启也会先看一次说明。

## 安全模型

- 种子 128-bit，首启 esp_fill_random 生成，存单个 NVS blob，永不离开设备。无网络、无蓝牙。
- 站点只存行/列/长度/模式与可选名称（13 字节）；密码永远是派生值，从不存储。普通密码是卡上格子流（v1.0 语义；迁移后的 v1.0 站点逐位不变）。PIN 是 4-6 位数字，来自同一种子 XOR「PIN1」域标记加站点位置钥匙的独立流：同种子可在任意设备重建，但永远不会出现在卡上——钱包卡被拍被抄也泄不出银行 PIN。
- 字母表去掉易混淆字符（0/O/o、1/l/I/i）：55 字符 ×5.78 bit。8 位密码约 46 bit 卡内熵；v1.2 的 16 位上限约 92 bit。这是防肩窥、防顺手翻查的防护，不是密码管理器、不防胁迫——威胁模型写进帮助页与本 PRD。
- 同种子即同卡；迁移 = 从旧机种子页抄走 32 个十六进制字符加两位 CRC-8 校验，在新机「恢复种子」里录入。有了校验，单个抄错字符（否则会静默变成另一张合法卡、所有密码全错）会表现为校验对不上。

## 字体与版式

- 拉丁/网格/密码用内建 Montserrat 12/14/20/28（ASCII 全覆盖；12 为 v1.2 新启用，服务 16 位明码）。密码明文字号按实测宽度 28→20→14→12 自适应，16 个宽字形密码不会溢出 220px 面板。
- 中文界面用霞鹜文楷 22px 4bpp 子集（源约 122KB），由 tools/pwcard/gen_assets.mjs 生成并做缺字审计（缺字即失败）。
- 主题：深色青色工具线；全部正文对比对实测 ≥4.5:1（色值与对比度表见英文 PRD 与设计稿）。

## 持久化

单个带版本 NVS blob（pwcard_v1/state）：版本、16 字节种子、站点数、首启标志、32 条站点记录（v1.2 布局 440 字节，每条多一个模式字节；v1.0 布局 408 字节）。读取时用一步纯函数（主机测试覆盖）把 v1.0 blob 转成 v2 并自愈回写闪存；版本或记录不匹配回落到全新默认。

## 闲置策略

12 秒背光调暗（55%→8%）、60 秒深睡，GPIO 按键唤醒并遵循仓库 key_guard 防误触契约；任意键重置闲置计时。显示倒计时独立计时，到零必遮回。

## v1.2 不做

种子同步/蓝牙、锁屏 PIN、种子二维码、多卡（后续候选，按真机反馈定）。
