# 口袋密码卡 - 离线派生密码卡

> 状态：新应用，2026-11-09 首次实现；待真机验证
> 硬件：FoloToy AI Passport（ESP32-C3，240×320 ST7789P3，三键 ADC，ES8311）
> 目标分支：feature/pwcard（基于上游 main）
> PRD 版本：v1.0（2026-11-09：初版——首次开机用 esp_fill_random 生成 128-bit 种子，经 xoshiro128\*\* 派生出固定的 8×10 字符网格；每个站点只是「行+列+长度」，密码就是同一条 80 格流上从该位置起的若干字符（越过末尾回绕）；密码默认遮蔽，OK 显示 8 秒倒计时后自动遮回，任何非 OK 键立即遮蔽；站名用三键转轮输入；种子可按十六进制查看，换设备抄写即可复现同一张卡；55 字符去混淆字母表 ≈5.78 bit/字符，8 位密码 ≈46.2 bit 卡内熵；闲置 12 秒背光调暗、60 秒深睡、按键唤醒）
> 模式：派生、回绕、种子十六进制、记录校验与闲置电源逻辑均为纯 C 可主机测试；C 侧生成流与 tools/pwcard/gen_assets.mjs 的独立实现在 tests/test_pw_core.c 交叉对拍

## 用法

开机进入卡视图：列头 A-J、行号 1-8 的 8×10 网格，游标行高亮。不进入硬件测试菜单。

- 卡视图：UP/DOWN 移动游标行（长按连发）。OK 进站点列表，长按 OK 进设置。
- 站点列表：UP/DOWN 选行，OK 看密码，长按 OK 回卡视图。列表末尾永远有一条固定的「添加站点」行（满 32 条后消失）。行内只显示站名——行列/列/长度摘要只在真正用到它的密码屏展示。页脚始终明示当前手势。
- 密码屏：默认遮蔽。OK 显示 8 秒并配缩短的倒计时条，到时自动遮回；再按 OK（或任意 UP/DOWN）立即遮蔽。长按 OK 返回。
- 添加向导：四步——行 1-8、列 A-J、长度 4-12、名称打字轮：UP/DOWN 滚动 7 格窗口（A-Z 0-9 连字符 点 空格，尾部有可见的「删」「完」条目）；OK 打入高亮条目（或删除/完成），长按 OK 取消。已打内容带下划标光标显示在轮上方。
- 设置：重生成卡（两次确认：旧密码全部失效）、查看种子（32 个十六进制字符）、清空站点（两次确认）、玩法说明。首启也会先看一次说明。

## 安全模型

- 种子 128-bit，首启 esp_fill_random 生成，存单个 NVS blob，永不离开设备。无网络、无蓝牙。
- 站点只存行/列/长度与可选名称（12 字节）；密码永远是派生值，从不存储。
- 字母表去掉易混淆字符（0/O/o、1/l/I/i）：55 字符 ×5.78 bit。8 位密码约 46 bit 卡内熵；这是防肩窥、防顺手翻查的防护，不是密码管理器、不防胁迫——威胁模型写进帮助页与本 PRD。
- 同种子即同卡；迁移 = 从种子页抄走 32 个十六进制字符。

## 字体与版式

- 拉丁/网格/密码用内建 Montserrat 14/20/28（ASCII 全覆盖）。密码明文字号按实测宽度 28→20→14 自适应，12 个宽字形密码不会溢出 220px 面板。
- 中文界面用霞鹜文楷 22px 4bpp 子集（源约 122KB），由 tools/pwcard/gen_assets.mjs 生成并做缺字审计（缺字即失败）。
- 主题：深色青色工具线；全部正文对比对实测 ≥4.5:1（色值与对比度表见英文 PRD 与设计稿）。

## 持久化

单个带版本 408 字节 NVS blob（pwcard_v1/state）：版本、16 字节种子、站点数、首启标志、32 条站点记录，显式尾部填充（主机测试静态断言尺寸）。版本或记录不匹配回落到全新默认。

## 闲置策略

12 秒背光调暗（55%→8%）、60 秒深睡，GPIO 按键唤醒并遵循仓库 key_guard 防误触契约；任意键重置闲置计时。显示倒计时独立计时，到零必遮回。

## v1.0 不做

种子同步/蓝牙、锁屏 PIN、种子二维码、多卡（v1.1 候选，按真机反馈定）。
