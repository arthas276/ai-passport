# ALMANAC v1.1 —— IT黄历：产品需求

给管服务器、机房和网络的人用的口袋黄历。它保留传统日课那一面——农历、节气、干支、建除十二神、
彭祖百忌、时辰吉凶、四吉方——再在上面印一层 IT 说法：这天宜忌什么（机柜收官、布线、打补丁、清工单），
幸运协议、端口、工具、颜色和数字，五条运势，以及择吉日。

设备离线、没有掉电走时的时钟：日期第一次要手设，深睡醒来还在，断电丢了会再问一次。

## v1.1 改了什么

- 界面：每块内容都落在带描边的卡片上，不再整屏一个深色底。宜、吉时、吉方、黄道日用青绿色块，
  忌、凶时、黑道日用朱砂色块；宜、忌各是一整块色块，标签是实心小方章。
- 日期：第一次开机、也没存过日期时，轮盘先落在固件的编译日期，不再是 2026-01-01。
- 换行：关于页不再把单个字甩到最后一行。

## 范围

- 目标机：FoloToy AI Passport（ESP32-C3、8 MB Flash、240×320 ST7789、三个按键）。
- 一屏一件事：一页页翻的日课卡，加一个管日期的菜单。
- 屏上一切都是确定的：同一天在任何设备上都印出同一张卡。
- 不联网、不用蓝牙、不出声。它就是一个随手看一眼的东西。

## 界面

每屏都是：居中标题（20 号字）、右上角电量（Montserrat 14）、中间内容带（y 38–262）、
底部两行提示条（y 268–312）。

| 屏 | 内容 | 提示第一行 | 提示第二行 |
| --- | --- | --- | --- |
| 今日 | 日期与星期、干支三柱、农历、建除印章、值神、宜/忌 | `上下 换日 · OK 详情` | `长按 菜单` |
| 详解 | 冲 / 煞 与一句释义、两条彭祖百忌、值神与日型一句 | `上下 换日 · OK 下一页` | `长按 菜单` |
| 时辰 | 十二时辰 4×3 格、每格吉凶、另列吉时与凶时 | `上下 换日 · OK 下一页` | `长按 菜单` |
| 吉方 | 四吉方加 IT 说法、幸运协议 / 端口 / 工具 / 颜色与数字 | `上下 换日 · OK 下一页` | `长按 菜单` |
| 运势 | 五类运势各一条星条与一句批注 | `上下 换日 · OK 下一页` | `长按 菜单` |
| 菜单 | 校准到今天 / 回到今天 / 择吉日 / 帮助 / 关于 | `上下 选 · OK 确定` | `长按 返回` |
| 择吉日 | 十二事项；结果列出未来 30 天内最多三个日子 | `上下 选事项 · OK 确定` | `长按 菜单` |
| 结果 | 选中的事项与吉日（带建除神） | `OK 重选` | `长按 菜单` |
| 设日期 | 年、再月、再日的轮盘（Montserrat 48 大数字） | `上下 选 · OK 确定` | `长按 取消` |
| 校准确认 | 选中的日期与「从今天起算」 | `OK 确定` | `长按 取消` |
| 帮助 / 关于 | 怎么用、出处与免责 | `OK 返回` | `长按 菜单` |

四个日课页成环：今日 → 详解 → 时辰 → 吉方 → 运势 → 今日。日期可以上下自由翻；翻到不是今天的日子，
日期右侧标「漫游」。

## 按键

| 键 | 单击 | 长按 |
| --- | --- | --- |
| 上 / 下 | 日期前后一天；菜单、事项表、日期轮盘里移动选择 | — |
| OK | 下一页；确认一项；日期轮盘进下一步 | 开菜单；退出菜单；取消编辑 |

每个能触发的动作都写在对应屏的提示条里；除此之外不绑任何动作，所以不存在隐藏手势。

## 传统那一层

- 农历含闰月，支持 1900-01-31 … 2100-12-31，由逐条核过的年表生成。
- 干支三柱：年柱按春节换、月柱按十二节换（月干由立春年五虎遁）、日柱按儒略日推。
- 建除十二神由日支对月支得；冲（所冲生肖）、煞（方位）与值神（十二值神）与时辰共用同一套表，
  所以吉时与吉日不会互相打脸。
- 彭祖百忌：日干一句、日支一句。
- 四吉方（财神 / 喜神 / 福神 / 阳贵）按日干取，福神与贵人用协纪派（不用口诀派里庚日阳贵、
  戊癸日福神的另一读法）。

## 抽条与规则

- 宜、忌各从 240 条词库里抽三条，六个面：机房、服务器、网络、数据与安全、工单与人、云与虚拟化。
- 按日号播种，所以同一天永远抽到同一组；1.1 互斥表挡掉同屏矛盾的搭配，宜被挡掉时换一条而不是少一条。
- 运势五类：服务器运、网络运、备份运、加班运、准时下班运，各一到五颗星。
- 择吉日：今天之后 30 天内，某日的建除神对该事项为吉、不为忌，且当天彭祖百忌不压该事项，才算吉日。

## 日期与时钟

- 一律中国标准时间（UTC+8），设备不设时区。
- 首次开机，或系统时钟落在 2020–2100 之外时，直接进日期轮盘；有确认过的日期就先用它，否则用固件的
  编译日期（`__DATE__`），两者都用不了才回到 2026-01-01。轮盘可以取消，回到今日卡（显示拨到的那一天）；日期确认之前，卡上日期位打一行提醒——存过日期而时钟丢了是
  「日期丢了，重设一下」，从没设过是「先设一个日期」。这时菜单里的「校准到今天」同样能把日期定下来。
- 确认会把系统时钟设到该日的当前时刻（首次为中午十二点），并把这一天存进 NVS。
- 系统时钟能过深睡，所以按一下醒过来，卡还是对的。
- 清醒时跨过零点，「今天」自动跟着翻。

## 电源

- 背光 55%，空闲 12 秒降到 8%，空闲 60 秒进深睡。
- 任意按键都重置空闲计时。
- 深睡按 BSP 要求的顺序把按键 GPIO 设成低电平唤醒，再依次挂起显示、音频、I2C 与电量计；进深睡
  由工作线程执行，不在 LVGL 线程里做。

## 渲染与字体

- 家族夜航蓝底（`#1B263B` 背景、`#24344D` 面板、`#3A4C6E` 描边、`#8D99AE` 次要文字），本应用的身份色是朱砂
  （`#E0533F`），用在印章、强调行和凶煞一类的色块上。
- 两套文楷子集（16 号与 20 号，867 字含 ASCII），加一套 48 号的建除十二神；字体从
  `main/almanac*.{c,h}` 的字符串字面量生成，缺字直接让生成器失败。
- 每块内容都是一张带描边的卡片：中性卡片用轨道色描边，选中行和正在调的数值用青绿描边，印章用朱砂
  描边。带含义的区块靠底色区分：宜、吉时、吉方、黄道日用夜航蓝向青绿（`#53D3B5`）调 28% 的色块
  （`#2B565D`），忌、凶时、黑道日用夜航蓝向朱砂调 28% 的色块（`#52333C`）。宜、忌各是一整块色块，
  标签是 22 像素的实心小方章，章里的字是夜航蓝。
- 版面由 `main/almanac_view.c` 排成场景：先列卡片，再给每一行一个落位窗口；`main/almanac_ui.c`
  只照场景画，不自己摆任何东西。
- 排版按真实字宽核：`tests/test_almanac_view.c` 用四年每一天检查每屏场景——卡片都在内容带内、
  互不半压，每一行按真实字宽落在自己的卡片里，不压别的行和卡片。

## 不做

- 不做自定义吉日（择吉日固定十二事项）。
- 不做节气页：节气只体现在月柱里。
- 不收农历日期：日期轮盘输入的是公历。
