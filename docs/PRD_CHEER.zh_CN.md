# CHEER - 夸夸精灵

> 状态：实现中
> 硬件：FoloToy AI Passport（ESP32-C3，240x320 ST7789P3，3 个 ADC 按键，ES8311）
> 目标分支：feature/cheer（自 upstream main 拉出）
> PRD 版本：v1.3（2026-11-17：场景点单、成长音阶、卡库扩容至 164、心爱收藏）
> 历史版本：v1.0（2026-10-22：首版——夸夸卡抽取、暖和弦风铃、精灵提亮成长、里程碑庆祝、
> 历史回看）；v1.2（2026-11-10：卡库扩容 124、断行平衡、电压显示、空闲深睡、系统堆分配）
> 模式：用户授权构建；风铃合成器移植自 feature/ear-buddy 的 ear_tone.c
>（同仓库，2026-10-20 已过真机验证）

## 1. 产品概述

- UI 名称：CHEER——挂在胸前的夸夸精灵
- 完全离线；无网络、无账号、v1 不使用麦克风
- 按 OK：精灵递给你一张暖融融的夸夸卡（简体中文）并配一声轻柔风铃；
  每收下一张卡，它的光就更亮一分；风铃音高随成长阶段升调
- v1.3 场景点单：OK 长按选场景（日常/上班/学习/勇气/夜猫子/出门在外/全部），
  只抽该场景的卡；选中的场景显示在标题旁
- v1.3 心爱收藏：翻看历史时长按 OK 收藏心爱的卡，收藏页单独回看，
  收藏每满 10 张奏一次庆祝和弦
- “夸夸袋”防重复：不放回抽取，抽完一整袋才重新洗牌——一袋之内绝不
  重复，重洗边界上也绝不连出同一张（单场景袋同样规则）
- 精灵随收集数提亮成长：6 个阶段，从微弱火种到满溢光华；升阶时
  奏响一段小型庆祝和弦

## 2. 硬件事实

- 板级基线同仓库指南；右上角电量百分比，下方一行显示电芯电压（bsp_battery_soc()/bsp_battery_mv()，
  -1 时显示 "--%" / "--.-V"）。读数缓存在 RTC 内存，深睡唤醒立即显示睡前值；
  30 秒 LVGL 定时器自动刷新，抽卡按键时即时刷新
- 无 RTC：成长只由终身收集数驱动，与日期无关
- v1 仅用 ES8311 播放（不采集）；Q15 整数波表合成器移植自
  EAR BUDDY 的 ear_tone.c（无 FPU 安全，约 1% CPU）
- 中文文本需要内置子集字体；见第 5 节

## 3. 行为、屏幕与按键

单一屏幕，全新设计 UI（非 demo 外壳）：

- 顶部："CHEER" 标题；标题右侧场景标签（v1.3，选中非全部时显示，如
  "SCENE: WORK"）；右上角电量百分比与电压
- 卡片中部：分类角标（Montserrat 14，DAILY/WORK/STUDY/BRAVE/
  NIGHT/OUT；v1.3 收藏卡追加 " FAV" 尾缀）在卡片文字上方，
  卡片文字使用内置中文字体，最多 3 行
- 卡片下方：精灵本体，程序化绘制的小光灵，调色板跨 6 阶段提亮
  （火种→微光→暖光→莹亮→熠熠→满溢；阈值 0/10/30/80/160/320 张，
  之后不设上限）
- 辅行："PRAISE n" 终身计数 + 下一阶段目标；满阶后显示
  "PRAISE n - MAX GLOW"
- OK 单击：抽下一张卡（袋子算法）+ 暖三音琶音（音高随成长阶段升调，
  阶段 ≥3 追加一个高八度闪音）；计数 +1；跨过阶段阈值时奏 5 音
  庆祝和弦，精灵提亮
- UP/DOWN：翻看抽取历史（最新在前，上限 CHEER_HISTORY_CAP；翻看
  不发声、不改变计数）；浏览后首次 OK 抽新卡；翻看中顶部显示
  "-n/N"（收藏卡附 " FAV"）
- OK 长按（v1.3）：卡片屏开场景选择器；翻看历史时收藏/取消收藏
  当前卡（屏上有提示行）
- 场景选择器（v1.3）：夜色浮层，行 = 全部/日常/上班/学习/勇气/
  夜猫子/出门在外/收藏；UP/DOWN 移动，OK 确认（选中场景立即抽
  一张，场景存 NVS 并显示为标题旁标签），OK 长按取消；选中
  "收藏"进入收藏浏览（UP/DOWN 翻看，OK 抽新卡退出，OK 长按
  取消收藏当前张，顶部 "Fn/N"；收藏每满 10 张奏庆祝和弦并
  顶部提示 "FAV n SAVED!"）
- 10 秒无操作背光降至 30%；60 秒无操作进入深睡，任意按键经 GPIO 低电平唤醒
  （约 0.6 秒回到就绪；每次开机重读电量/电压，电量计挂起/重启时序同仓库低功耗
  demo 契约）

## 4. 技术架构

main/
  cheer.h           - 共享常量（[PURE] 头文件）
  cheer_cards.c/.h  - [PURE] 夸夸卡文库（164 条、6 组：4×31 + 夜猫子/
                      出门在外各 20）与洗牌袋引擎（xorshift32 上的
                      Fisher-Yates，重洗边界不连出；场景袋从连续分组
                      窗口抽取）+ 阶段数学；零 IDF/LVGL 依赖
  cheer_fav.c/.h    - [PURE] 心爱收藏列表（上限 32、NVS blob 序列化、
                      每满 10 里程碑数学）。v1.3
  cheer_tone.c/.h   - [PURE] Q15 波表合成器，移植自 ear_tone.c
                      （LUT + 3 分音 + 起音/衰减/收音包络）+ 成长
                      音阶音符表。v1.3
  cheer_audio.c/.h  - worker 任务：串行化 bsp_audio 调用；按成长阶段
                      变调播放抽卡琶音与升阶和弦（阶段 ≥3 加八度闪
                      音）；音量固定 80
  cheer_store.c/.h  - NVS 持久化：终身计数（"cc"）、场景（"sc"）、
                      收藏 blob（"fv"）、收藏里程碑高水位（"fm"）；
                      旧版设备缺键时按默认值迁移
  cheer_ui.c/.h     - 单一 LVGL 屏：卡视图（收藏 FAV 尾缀）、历史翻看、
                      模态场景选择器、动态模式提示、程序化光灵
                      （6 套调色板）、背光闲置管理
  cheer_font.c/.h   - 生成的中文子集字体（28 px，4 bpp），覆盖且仅
                      覆盖卡文库全部用字
  main.c            - BSP 初始化 -> 按键分发（卡片/选择器/收藏三模式）
                      -> 抽卡 -> UI/音频
tests/test_cheer_cards.c - 文库完整性、袋子耗尽/不重复、阶段阈值、
                      分组区间连续、场景袋窗口、rng 防卡死
tests/test_cheer_fav.c   - 收藏开关/上限/序列化/里程碑。v1.3
tests/test_cheer_tone.c  - LUT 峰值、结束静音、不削波、成长音阶单调

tests/test_cheer_ui_budget.c - Montserrat 14 镜面文案像素预算
                      （冻结字宽表）。v1.3

[PURE] 模块以 cc -std=c11 -Wall -Wextra -Werror 编译，注册进
tools/validate.sh。袋子状态仅存 RAM（每次开机重新洗牌）；仅终身计数
持久化到 NVS。

## 5. 中文字体管线

- 字源：Noto Sans SC（SIL OFL 1.1）；子集 = CHEER_CARDS[] 全部唯一
  字符 + 卡面使用的全角标点
- 生成：tools/gen_cheer_font.sh 用 lv_font_conv --size 24 --bpp 4 按
  解析出的字符集生成，产物提交为 main/cheer_font.c，仅在文库变化时
  重新生成
- 体积估算：约 420 唯一字 × 约 200 B = 85-130 KB flash；app 分区尚有
  约 7 MB 余量
- 按 docs/development/engineering/lvgl-chinese-fonts.md：静态门禁编译
  覆盖检查（tests/test_cheer_font.c），断言每张卡的每个字符都在生成
  字体内有字形

## 6. 风险与 AI 默认决策

| 决策 | 取值 | 理由 |
| --- | --- | --- |
| 卡量 164 条、4 组×31 + 2 组×20 | 多样性不臃肿 | 整袋一轮 = 164 抽不重复 |
| 场景点单 = OK 长按 | 不新增按键 | 选择器行号即场景号，存 NVS |
| 收藏上限 32、每满 10 里程碑 | NVS blob 体积 | 每次切换重写 64 B，代价低 |
| 6 阶段 0/10/30/80/160/320 | 对齐 EAR BUDDY 节奏 | 已验证的成长韵律 |
| 历史上限 20 条 | RAM 边界 | LVGL 标签复用 |
| 卡面中文、界面英文 | 受众以中文为主 | 标题/提示维持 Montserrat |
| v1 无麦克风/无 TTS | 今天可交付 | 韵律相关想法延后 |
| 风险：固定文案会衰减 | 84 卡袋 + 阶段追逐 | 评审指出的弱点 |
