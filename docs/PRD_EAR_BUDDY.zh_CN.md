# EAR BUDDY 口袋练耳伙伴 - 产品需求文档

> 状态：可进入固件实现
> 硬件：FoloToy AI Passport（ESP32-C3，240x320 ST7789P3，三 ADC 按键，ES8311）
> 目标分支：feature/ear-buddy（自 main 建立）
> PRD 版本：v1.7（2026-10-20：VS 对战模式——两人轮流作答 10 道听辨题，
> 共享宠物每次答对都得 +1 XP，无满勤奖励/难度调整；终局段位延伸成长线——
> 演奏家 320 / 大师 640 / 传奇 1280，仅沿用鸣禽结构与色板递进）；
> v1.6（2026-10-18：听辨音程加入下行与和声方向——L2 起混入下行、
> L3 起混入和声，判分与难度规则不变）；v1.5（2026-10-18：重置改为全屏二次确认页——首次长按进入，5 秒内
> 再长按执行，任意键取消）；v1.4（2026-10-17：旋律听写——听一段旋律，唱回来；见 3.4）
> 日期：2026-09-28
> 模式：用户预先授权通宵自主开发；AI 自行决定了第 10 节列出的默认值；
> 真机验证安排在次日晚间用户在场时进行。

## 1. 产品概述

- UI 名称：EAR BUDDY，口袋练耳工具 + 轻量宠物养成
- 内部前缀：ear_
- 完全离线；无网络、无账号；进度存 NVS
- 用户已用 xiaozhi.me 固件验证同一硬件的 Wi-Fi+麦克风+扬声器链路
- 背景：用户最初考虑 NFC 门卡模拟 - 不可行（NTAG213 是被动标签，无 MCU
  接口）；改选音频方向；用户选定三个模式：音程+和弦听辨、唱音准、宠物养成

## 2. 硬件事实（bsp_pins.h / specs / AGENTS）

- ESP32-C3，8MB Flash，无 PSRAM，LV_MEM 24KB - UI 轻量，无全屏动画
- 无 RTC 时间源 - MVP 不做日期/连续打卡功能（与番茄钟 PRD 同样取舍）
- sdkconfig 只启用 Montserrat 14/20 - MVP UI 用英文；中文 UI 需要
  lv_font_conv（node.js），推迟并列在 Unverified
- ES8311：采样率切换走 bsp_audio_set_format（内部 close/open）；PCM 阻塞；
  所有音频操作串行在单一 worker task
- 电量按仓库默认约定显示在右上角（bsp_battery_soc()，-1 显示 --%）；
  SETUP 页加显 SOC% + 电芯电压（v1.1，CW2017 profile 未按实芯标定）
- 空闲 10 秒背光调至 30%，任意按键恢复 100%（仓库功耗约定）

## 3. 模式与规则

### 3.1 听辨（音程/和弦）

- 一局 10 题；根音 C4-A4；方向随级别（v1.6）：L1 仅上行，L2 上行/下行均匀混合，
  L3 上行/下行/和声均匀混合；答案只认音程种类，与方向无关
- 选项集随难度：
  - 音程：L1 {m3, M3}；L2 {m3, M3, P4, P5}；L3 {m2, M2, m3, M3, P4, P5}
  - 和弦：L1 {maj, min}；L2 {maj, min, dim, aug}；L3 {maj, min, dim, aug, M7, 7}
- 答题：UP/DOWN 移光标，OK 确认；答对 +1 XP，宠物跳 + 开心音效；答错高亮
  正确项并回放正确答案，进入下一题；不扣分
- 每模式自动难度：局末 score>=8 升一级（上限 3）；<=4 降一级（下限 1），NVS 保存
- 连击仅作展示
- 音色：加性合成（f + 0.40*2f + 0.18*3f，v1.3 调浓），快攻击 + 缓衰减至
  ~64% + 8ms 释放坡，16000Hz 16bit（板上验证过的采样率；22050 实测失真）
  单声道；音程 = 两音各 650ms 间隔 120ms（下行 = 高音先响，同参数；和声 =
  两音同时 1250ms，走和弦混音路径）；和弦 = 三音齐奏 1250ms；唱音准
  目标音预听 950ms（v1.3：按用户要求更长更饱满）

### 3.2 唱音准

- 播放目标音（C4-A4），屏显音名，UP 重听，OK 开始收音（最长 4 秒）
- 16kHz 采集 -> 1024 点自相关 f0（65-600Hz；v1.1 最早显著峰 + v1.3 整数
  分频复核，防八度误判）-> median-3 平滑 -> 音分偏差 = 1200*log2(f0/f_target)
- 保持 |cents| <= 容差达 1.0 秒判 PASS；容差 L1 ±80、L2 ±55、L3 ±35 音分
  （v1.1 重调：检测修复后旧值仍卡初学者）；PASS +2 XP
- 八度等价判定（v1.2）：音分折叠到 ±600，唱对音高类即算通过；屏显
  OCT-LOW/OCT-HIGH 提示
- 同一目标音失败 3 次后设备播放正确音（show answer）进入下一音；一组
  5 音，结束进共用 RESULT 结算页并显示生涯统计（v1.2）

### 3.3 二重唱（v1.3）

- 回合制：用户唱一句 2-4 秒；设备转写成音符序列、推断调性，然后把这句
  作为二重唱回放：旋律回声 + 一个和声部；每个音符宠物跳一下；每完成
  一次二重唱 +3 XP（决策：按次计，不搞固定局数）
- 采集：与 SING 同一条 16kHz 链路（八度安全 f0 + median-3）。窗口最长
  4 秒；确认音符 >= 2 个后静音 0.8 秒即提前结束
- 分段 [PURE ear_duet.c]：帧 -> 最近半音；新音连续 3 帧稳定（约 192ms，
  即 >= 190ms 下限）才确认；音内抖动 ±70 音分内算同一音（防颤音切分）；
  无声间隔 >= 350ms 结束当前音；最多保留 12 个音符
- 调性推断 [PURE]：时长加权音级直方图（首尾音符各加 50% 锚定权重——旋律
  首尾多落主音）对 24 个大/小调模板打分；优势弱（第一名领先第二名的
  幅度 < 总时长 10%）或不同音级 < 3 个 -> 回退：以最重音级为主音、
  按大调处理（嗡唱/两音短语）。八度翻唱无需特判：音级本身折叠八度
  （男声低八度直接可用）
- 和声（按阶段解锁，取推断调内的自然音级）：
  蛋/破壳 = 齐唱回声（弱音量双声部）；雏鸟 = 调内三度（下方优先，
  低于 C3 时取上方）；幼鸟 = 调内六度（同规则）；鸣禽 = 逐音在三度/
  六度间选连接最平滑者（和声步进最小）。声部限制在 MIDI 48..81
  （C3..A5）；超过 A5 折下八度（即 > 880Hz 规则）
- 回放：旋律振幅 0.9 + 和声 0.6 + 和声高八度加倍 0.45，走整数合成器（八度
  加倍让和声在小扬声器上可闻——贴近的音程会被掩蔽成单个更厚的音）；每音
  时长 = 采集时长（截到 200..900ms）+ 80ms 间隔；REVIEW 页先展示转写与调性再播放
- 确认音符 < 2 个 -> "TOO SHORT" -> OK 重唱

### 3.4 旋律听写（v1.4）

- 与二重唱思路相反：设备先播放一段短旋律，用户唱回来，逐音判定（宠物经济、
  NVS 持久化与 3.1 相同）
- 一局 10 段旋律，用听写级别 dlvl（初始 1，与其他模式级别一样跨局保留）：
  LV1 三段、LV2 四段、LV3 五段；LV1 范围 C4-G4 且末音落在 C 大三和弦
  （高级别扩大音域与跳进幅度）；相邻两音不重复
- 五状态：READY（展示旋律）-> LISTEN（播放，宠物逐音跳）-> ECHO（OK 开始收音，
  UP 重播）-> SING（收音，与二重唱同一链路，上限 4s：确认到预期音数后
  静默 0.8s 结束；未到预期音数时只有 1.6s 停顿才结束，唱歌中间可以想
  一下）-> GRADE（判定 + XP）-> 下一段或 10 段后 RESULT。LV1 播放更慢
  （每音 560ms，LV2 420ms、LV3 360ms），三段短旋律更容易记住
- 判定 [PURE ear_dictation.c]：整句八度折叠，由第一个唱出的音决定折叠方向
  （整体高八度/低八度都算对；句中临时换八度仍判该音错）。折叠后按级别收紧
  音准容差：±90 音分（LV1 EASY）、±70 音分（LV2 NORMAL）、±50 音分
  （LV3 STRICT）——LV1 比转写器自身的 ±70 音分抖动窗口更宽，初学者的
  晃动不会丢音；LV3 要求唱准四分之一音内。容差均不足一个半音，因此再
  容易的档位下唱错音名也一定判错。
  目标音按顺序逐个匹配，每个位置最多可跳过 2 个多唱的音（记 EXTRA），
  因此多唱一个音不会让后面的音整体错位；匹配不到的记 MISS
- 奖励：全对（无 MISS 无 EXTRA）+2 XP；目标音全部 OK +1 XP；过半目标音 OK
  +1 XP（唱对一半也有奖励，XP 永不下降）；再低不得分。不足 2 音 -> "TOO SHORT"
  重收音；局末按与听辨/唱歌相同的 auto 级别调整
- 按键：OK 推进状态；ECHO 下 UP 重播旋律；OK 长按退局（已得 XP 保留）；
  RESULT 累计行显示生涯唱对旋律数

### 3.5 VS 对战模式（v1.7）

- 一台设备两名玩家：10 道听辨题 P1/P2 轮流作答（P1 先手），采用当前
  音程级别；题头显示当前作答玩家与比分（"Q 4/10 P2 3:2"，金色）
- 任一玩家答对，共享宠物都得 +1 XP；答错重播正确答案（与单人听辨
  相同的教学反馈）
- 对战无满勤奖励、不做难度调整：级别仅由单人模式驱动；生涯最佳连击
  保持单人统计口径
- 终局：判定页（"P1 WINS!" / "P2 WINS!" / "DRAW!"）+ 最终比分 + 本局
  XP；OK 回主页；OK 长按中途退局（已得 XP 保留）
- 计分 [PURE ear_vs.c]：回合 = 题序奇偶；比赛结束后再 record 会被忽略
  （不污染比分与题序）

### 3.6 宠物经济

- 阶段阈值（累计 XP）：蛋 0 -> 破壳 10 -> 雏鸟 30 -> 幼鸟 80 -> 鸣禽 160
  -> 演奏家 320 -> 大师 640 -> 传奇 1280（v1.7 终局：鸣禽之后继续成长，
  传奇为最终段位）
- XP 来源：听辨答对 +1；满勤（10/10）+3；唱准 +2/次；二重唱 +3/次（v1.3）；
  听写全对 +2、目标音全 OK +1、过半目标音 OK +1（v1.4）；对战答对 +1，
  任一玩家均计（v1.7）
- 反应：答对宠物跳 + 音效；答错摇头；进化 = 阶段图切换 + 号角 + 跳 x3
- XP 永不减少；NVS 读取失败按新宠物处理，不崩溃

## 4. 画面与按键（重新设计，不沿用 demo 外壳）

HOME：标题 + 右上角电量；宠物图 48x48 居中；XP 条 + 文本；底部模式卡
（INTERVAL/CHORD/SING/DUET/DICTATION/VS BATTLE/SETUP，UP/DOWN 切换，OK 进入；
v1.3 增 DUET，v1.4 增 DICTATION，v1.7 增 VS BATTLE）。
QUIZ（单人与对战共用）：头部 "Q 3/10 LV2"；对战头部 "Q 4/10 P2 3:2"
（金色，v1.7）；状态行 LISTEN.../判定反馈；选项网格 2/4/6 格；
底部按键提示。UP 长按重播题目；OK 长按退局（已得 XP 保留）。
SING：目标音名大字；横向音分标尺 + 移动标记 + 保持进度条；UP 重听；OK 开始
收音；OK 长按退出。
DUET（v1.3，五状态）：READY 显示阶段和声档（UNISON/3RD/6TH/VOICE-LEAD），
OK 开始；LISTEN 实时显示已识别音符数与音名，采集自动结束；REVIEW 展示
转写（最多 12 音）+ 推断调性（如 "C maj"），OK 播放、UP 重唱；PLAY 旋律
+ 和声回放，宠物逐音跳；DONE 显示 +3 XP 与生涯次数，OK 进下一回合。
DICTATION（v1.4，五状态）：READY 显示 "DICTATION" + "MELODY 1/10 LV1 EASY" +
旋律音名，OK 播放；LISTEN 播放中宠物逐音跳（按级别每音 560/420/360ms），播完进
ECHO；ECHO 旋律留在屏上作目标，"OK SING UP REPLAY OKL EXIT"；SING 实时显示音符数
与音名，转写自动结束；GRADE 显示 "PERFECT! +2 XP" / "RIGHT! +1 XP" /
"CLOSE 2/3 +1 XP" / "WRONG 1/3" 与唱回的音名（对绿错红），OK 进下一段，10 段后进
RESULT。
RESULT：SCORE n/10 + 本局 XP + 宠物跳动画；OK 回主页（有进化则庆祝）。
对战终局（v1.7）："P1 WINS!" / "P2 WINS!" / "DRAW!" + "P1 6 : 4 P2" + XP。
SETUP：UP/DOWN 调音量（±10，立即生效），OK 保存返回；OK 长按进入全屏重置确认页
（RESET ALL PROGRESS?：5 秒内再长按执行并回主页，任意键取消；v1.5 落地）。
全局：任意按键与音频事件都刷新空闲计时；10s 空闲背光 30%。

## 5. 数据与持久化

NVS namespace earbuddy：xp u32；ilvl/clvl/slvl u8（1-3）；vol u8（0-100）；
answered u32；sing_pass u32；best_combo u8（生涯统计，v1.2）；
duets u32，键 "du"（生涯二重唱次数，v1.3，旧档默认 0）；
dlvl u8（听写级别 1-3），键 "dl"；melodies u32，键 "mel"
（生涯目标音全部 OK 的旋律数——部分给分只加 XP，不计入此项；v1.4 两项，
旧档默认 1 / 0）。
读取失败按默认（新宠物）；XP 变化即写（每局 1-2 次，NVS 磨损无忧）；写失败仅日志。

## 9. 交付报告格式

Build / Host tests / Device tests / Unverified 分报。烧录与真机验收在次日晚
进行（需用户授权烧录）。今晚交付 = 代码 + PRD + host tests + 固件构建。
